# Tone-of-voice dimensions (register rubric)

A citable rubric for the register-fit section of a brand-voice audit. Use it to
turn "this feels off" into a specific, defensible flag — either against the
project's own register matrix, or (when no matrix exists) as the generic
fallback standard.

## The four dimensions (Nielsen Norman Group)

NN/g's tone-of-voice model places any piece of copy on four independent
spectrums. A register isn't one point — it's a target position on each of the
four. Score the draft 0–10 on each and compare to where the target register
should sit.

| Dimension | 0 ⟶ 10 | What a mismatch looks like |
|---|---|---|
| **Funny ⟷ Serious** | 0 = playful/humorous, 10 = strictly serious | Jokes in a compliance notice; deadpan in a birthday promo |
| **Casual ⟷ Formal** | 0 = conversational/contractions, 10 = formal/structured | Slang in a B2B proposal; stiff legalese in a consumer caption |
| **Irreverent ⟷ Respectful** | 0 = cheeky/boundary-pushing, 10 = deferential/earnest | Snark toward a bereaved reader; over-formality that reads cold |
| **Enthusiastic ⟷ Matter-of-fact** | 0 = high-energy/exclamatory, 10 = neutral/reporting | Exclamation-heavy hype in a methodology section; flat tone in a launch |

Source: Nielsen Norman Group, "The Four Dimensions of Tone of Voice"
(https://www.nngroup.com/articles/tone-of-voice-dimensions/).

## How to use it in an audit

1. **Pin the target.** From the project's register matrix row for this
   audience, or from the user if no matrix exists, state the target position on
   each of the four dimensions (roughly — "casual-ish, warm, matter-of-fact,
   respectful" is enough).
2. **Score the draft.** Read the draft and place it on each dimension. Cite the
   phrase that moved your score (e.g. three exclamation points → pushes
   Enthusiastic below target).
3. **Flag the gaps.** Report only the dimensions where the draft is off target,
   with the quoted phrase and a one-line fix — consistent with this skill's
   flag-don't-rewrite rule. A dimension that's on target needs no flag.

## Note on register vs. these dimensions

A project's own register matrix (from the voice card) is always the primary
standard — it encodes vocabulary and cross-contamination rules these four
generic axes don't. Use these dimensions to *express* a register judgment
crisply, not to override a documented register matrix when one exists.
