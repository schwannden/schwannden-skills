# PR repurposing: press-release anatomy, boilerplate, media kit

Reference for the PR conventions behind press repurposing — the anatomy of the
clip you're reusing, the reusable brand block every recap should carry, and the
media-kit assets a repurposing program feeds.

**Sections:** [Press-release anatomy](#press-release-anatomy) · [Boilerplate](#boilerplate-the-reusable-brand-block) · [Media kit](#media-kit-components) · [Atomizing one clip](#atomizing-one-clip)

## Press-release anatomy

Knowing the standard parts helps you locate the real quote, stat, and angle in
a clip (and recognize a thin one). A conventional release runs:

- **Headline** — the news, in one line; the recap's title often reworks this.
- **Dateline** — city + date the news is issued.
- **Lede** — the first paragraph, carrying who/what/when/where/why; the
  inverted-pyramid top.
- **Body (inverted pyramid)** — most important facts first, detail after, so it
  reads even if cut short.
- **Quotes** — attributed statements from named people; a real pull-quote for
  the recap comes from here.
- **Boilerplate** — the standing "about the organization" paragraph (below).
- **Contact** — media contact for follow-up.

Pull-quotes and stats for any repurposed asset must trace to real sentences in
the clip — the anatomy tells you where to look, not license to invent.

## Boilerplate — the reusable brand block

The **boilerplate** is the short, standing "About [org]" paragraph that closes
a release and repeats verbatim across coverage. Treat it as a reusable asset:
keep one canonical version (sourced from the fact sheet's positioning line +
headline stat), and reuse it at the foot of every blog recap and in the ESG
snippet so the brand description stays consistent everywhere. Don't rewrite it
per piece — that's how the description drifts.

## Media-kit components

Repurposing feeds, and draws from, a media/press kit — the downloadable set an
outlet needs to cover the org without asking:

- Boilerplate + one-line and one-paragraph descriptions
- Fact sheet (stats, milestones, timeline)
- Leadership bios + headshots
- Logos in usable formats + brand-color note
- Approved photography / b-roll
- Awards / recognition
- Media contact
- An "as featured in" / coverage list — which the media-coverage inventory
  this skill maintains directly supplies.

If the project lacks a media kit, note the gap; the fact sheet + coverage
inventory from `building-brand-kits` already cover most of it.

## Atomizing one clip

One earned-media hit is raw material for many assets (this skill produces the
blog recap, social captions, and ESG snippet). Other standard atomizations
worth noting to the user: an "as featured in" logo bar for the site, a
newsletter mention, and a sales-enablement leave-behind. Each must still carry
a real quote/stat from the clip and a backlink to the original outlet.
